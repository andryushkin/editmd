# smotr — память проекта EditMD

## Подключение
- `contentDir`: `docs` · порт `8000`
- Лаунчер: `docs/review/run` (тонкая обёртка → `~/Server/smotr/serve.py --root <корень>`)
- Запуск: `./docs/review/run --no-open` (в фоне), URL `http://localhost:8000`
- gitignore: `*.baseline`, `.smotr-queue.json`, `.smotr-agent.log` добавлены

## Дизайн-токены (источник истины — код приложения)
- **Палитра**: `EditMD/EditMD/Editor/EditorTheme.swift` — темы `.system`
  (адаптивные NSColor) и `.github` (hex через `gh(light,dark)`). Ключевые:
  accent/link = `.linkColor` (github `#2c65cf`/`#4c8ef8`), inline code =
  `.systemOrange` (github `#d1242f`/`#ff7b72`), image = `.systemGreen`.
- **Per-mode шрифт/отступы/элементы**: `EditMD/EditMD/Views/EditorSettings.swift`
  (`ModeSettings`, `ElementStyles`, `GeneralSettings`, `AppearanceMode`).
- **Preview CSS**: `previewHTMLPage` в `EditMD/EditMD/Editor/MarkdownHTML.swift`
  (H1/H2 `2em`/`1.5em` + нижняя линия `rgba(128,128,128,.3)`, code `.9em` mono).
- **Тулбар/сплит/статус**: `EditMD/EditMD/Views/ContentView.swift`
  (плоские иконки agterm-стиля, 3 кнопки режимов + split + palette + sun/moon).
- **Settings-окно**: `EditMD/EditMD/Views/SettingsView.swift` (TabView 720×720,
  grouped-форма, вкладки General/Source/Visual/Preview).

## Дизайн-папка
`docs/design/` — HTML-прототипы, один файл = один экран. Индекс — `docs/design/index.md`.

## Конвенции
- Прототипы **theme-aware** (`prefers-color-scheme`), совпадают с System-темой app.
- Единый пример-документ «Release Notes — v27» во всех трёх режимах (сравнение рендера).
- macOS window chrome: traffic lights + тулбар/таб-бар; иконки — inline SVG sprite.
- Имена файлов с числовым префиксом (`01_…`) для порядка в дереве.
